# Contributing

Use Node.js 24 or later. Run `npm ci`, `npm test`, `npm run check:public`, and
`npm start`. The default build needs no cloud account or restricted DevKit.

Keep changes small and include tests. Preserve source attribution and reversible
user choices. Do not add hidden collection, automatic social actions, arbitrary
model-generated JavaScript, or implicit uploads of page content. Do not commit
credentials, browsing profiles, private feed samples, or screenshots of accounts.
Use synthetic fixtures instead. Review PRIVACY.md and SECURITY.md first.

Contributions you submit for inclusion must be your own or properly licensed,
and are submitted under this project's MIT license. Preserve dependency notices.
Do not copy optional restricted integration code into public files or fixtures.
Run the public checks before submitting a pull request. Community contributions
do not imply approval by Facebook, OpenAI, or any publisher.
